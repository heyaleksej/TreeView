# Angular Tree View Демонстрация

Этот проект демонстрирует реализацию компонента "дерево" (Tree View) в Angular с использованием mock-данных. Реализованы следующие возможности:

- Рекурсивный рендеринг дерева: Узлы отображаются с возможностью вложенности.
- Динамическая стилизация: При пометке узла как удалённого (is_deleted: true) применяются специальные стили серый цвет).
- Условное отображение стрелки: Если у узла есть дочерние элементы, отображается стрелка для сворачивания/разворачивания.

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 19.0.0.

To start a local development server, run:

```bash
ng serve
```
